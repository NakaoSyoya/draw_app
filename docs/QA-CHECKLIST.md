## 1. 新規作成とキャンバス

- [ ] 起動時に「横（HD）1280×720」のキャンバスが白で表示される
- [ ] ウィンドウを狭めるとキャンバスが縮小表示され、アスペクト比が保たれる
- [ ] ウィンドウを広げても原寸（1280×720）より大きくはならない
- [ ] 「新規作成」→ 確認ダイアログ →「新規作成する」→ プリセット一覧が出る
- [ ] 各プリセット（5種）を選ぶと、その寸法の白いキャンバスになる
- [ ] 同じプリセットを選び直しても白紙に戻る
- [ ] 確認ダイアログで「キャンセル」すると何も起きない

## 2. ブラシ・消しゴム

- [ ] ドラッグで線が引ける。速く動かしても線が途切れない
- [ ] 色を変えると次の線に反映される
- [ ] 太さスライダーが線の太さに反映される
- [ ] 不透明度を下げると薄い線になる。同じストローク内で交差した箇所が濃くならない
- [ ] 消しゴムで白く消せる
- [ ] 消しゴム選択時は「色」と「不透明度」が設定パネルから消える

## 3. 図形・直線

- [ ] 矩形・楕円をドラッグで描ける。離しても**まだ確定しない**（点線の枠が残る）
- [ ] 未確定の図形の内側をドラッグすると移動する（角に飛ばない）
- [ ] 角・辺のハンドルをドラッグするとリサイズできる
- [ ] 反対側を越えてドラッグすると図形が反転する
- [ ] 「図形を塗る」をオンにすると内部が塗られる
- [ ] 直線は端点をドラッグして向きを変えられる
- [ ] `Enter` で確定、`Esc` で破棄できる
- [ ] 別ツールに切り替えると自動で確定される
- [ ] 図形の外側をクリックすると確定し、その場から新しい図形を描き始める

## 4. 塗りつぶし

- [ ] 白い領域をクリックすると塗られる
- [ ] 線で囲まれた内側だけが塗られ、線を越えない
- [ ] すでに同じ色の場所をクリックしても何も起きない（取り消しが増えない）
- [ ] 不透明度を下げて塗ると、下地と混ざった色になる

## 5. テキスト

- [ ] クリックした位置に入力欄が出て、すぐ入力できる
- [ ] **日本語入力（IME）で変換できる。変換中に `B` などを押してもツールが切り替わらない**
- [ ] 左上のハンドルをドラッグすると文字の位置が動く
- [ ] 文字サイズスライダーが反映される
- [ ] `Enter` で確定、`Esc` で破棄
- [ ] 何も入力せずに確定しても何も描かれない（取り消しが増えない）

## 6. 取り消し・やり直し

- [ ] 線を引く →「取り消し」→ 消える →「やり直し」→ 戻る
- [ ] 20 ステップまで戻れる
- [ ] 戻る先がないとき「取り消し」ボタンが**明らかに押せない見た目**になっている
- [ ] 取り消した後に新しく描くと「やり直し」が押せなくなる（線形履歴の仕様）
- [ ] `Ctrl`(`Cmd`)+`Z` / `Ctrl`+`Shift`+`Z` / `Ctrl`+`Y` が効く
- [ ] キャンバス上でマウスを動かすだけ（押さずに）では何も起きない

## 7. 保存・クリア

- [ ] 「PNGで保存」で `drawing-YYYYMMDD-HHmmss.png` がダウンロードされる
- [ ] 保存した PNG の背景が白で、画面の見た目と一致する
- [ ] 未確定の図形がある状態で保存すると、確定されてから書き出される
- [ ] `Ctrl`(`Cmd`)+`S` で保存できる（ブラウザの保存ダイアログが出ない）
- [ ] 「クリア」→ 確認 → 全体が白に戻る
- [ ] クリアを「取り消し」で元に戻せる

## 8. キーボード操作・アクセシビリティ

- [ ] `B` `E` `L` `R` `O` `G` `T` でツールが切り替わる
- [ ] `[` `]` でブラシの太さが変わる
- [ ] `Tab` だけでツールバーと設定パネルを操作できる
- [ ] フォーカスされた要素に枠が見える
- [ ] ダイアログを開いている間、`Tab` がダイアログ内に留まる
- [ ] ダイアログは `Esc` で閉じる。閉じるときにキャンバスの未確定オブジェクトが消えない

## 9. PWA / オフライン

- [ ] アドレスバーにインストールアイコンが出る（Chrome / Edge）
- [ ] インストールすると単独ウィンドウで起動する
- [ ] 一度読み込んだ後、**ネットワークを切断して再読み込み**しても起動する
- [ ] オフラインのまま、描画・取り消し・PNG 保存まで全部できる
- [ ] DevTools > Application > Manifest にエラーが出ていない
